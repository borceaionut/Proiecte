# 💎 C++ Console Patterns & Algorithms

This folder contains academic and personal projects developed in C++, focusing on algorithms, logic structures, and console applications.

## 📁 Projects Included

### 1. Geometric Pattern Generator (Romb.cpp)
* **Description:** A console application that dynamically renders a symmetrical diamond (romb) shape using nested `for` loops.
* **Key Concepts:** Control flow, nested loops, space management in console output, and colored text output using terminal manipulators.

## 🚀 How to Run the Code Local

1. Navigate to this directory in your terminal:
   ```bash
   cd CPlusPlus_Console
   ```
2. Compile the source file using a C++ compiler (like `g++`):
   ```bash
   g++ Romb.cpp -o Romb
   ```
3. Execute the generated file:
   * **Windows:** `Romb.exe`
   * **Linux/macOS:** `./Romb`
